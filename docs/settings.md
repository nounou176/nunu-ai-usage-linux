# Settings

## Usage display mode

Supported values:

- left: show remaining quota, for example 87% LEFT.
- used: show consumed quota, for example 13% USED.

Default: left.

The progress bar follows the selected mode.

## Refresh

Default: 60 seconds.

## Widget monitor

Default: primary.

## Widget anchor

Supported anchors:

- top-right
- top-left
- bottom-right
- bottom-left

Default: top-right.

## Keep visible

When enabled, NUNU must detect monitor layout changes and move the widget back onto a visible monitor if its previous coordinates become invalid.
